# Design System Phase 1 — Tokens Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Author the Shroom Games design values (colors, radii, spacing, typography primitives) once in a DTCG token file and generate Swift (ShroomKit) + CSS (marketing site) from it via Style Dictionary — migrating colors now, defining the rest for later adoption.

**Architecture:** A `tokens/` directory in the ShroomKit repo holds `tokens.json` (DTCG) and a Style Dictionary config. An `npm run build:tokens` script generates: the existing `Palette.swift` (regenerated from color tokens, public API frozen), a new `Tokens.generated.swift` (radii/spacing/type primitives), and `tokens.css` (CSS custom properties). The generator bridges two existing naming schemes — Swift property names and the site's `--shroom-*` CSS variable names — via a per-token name map, so neither platform's existing surface breaks. ShroomKit is a SwiftPM package, so `swift build`/`swift test` validate headlessly; only a final both-apps build is GUI-bound.

**Tech Stack:** Node.js + Style Dictionary v4 (DTCG-native), Swift 6 / SwiftUI / Swift Testing, static HTML/CSS site with `data-theme` attribute theming.

## Global Constraints

- **Token format:** DTCG (design-tokens.org W3C community group) — `$type`/`$value` keys.
- **Generator:** Style Dictionary v4 (`style-dictionary@^4`), DTCG-native.
- **Home:** `shroomkit/tokens/` — token source + config co-located with generated Swift.
- **Swift `Palette` public API is FROZEN** — same struct, same property names (`appBg`, `sub`, `tierBg`, …), same statics (`forest`, `twilight`, `palette(for:)`), same `warn` alias. Only literal values are generated. Both apps consume it unchanged.
- **`numberColors`** — ordered 9-slot array per theme; slot 0 is the literal `.clear` (a sentinel, not a token); slots 1–8 are color tokens.
- **`warn`** is a derived alias of `mushroomCap` — a token reference, not a duplicated value.
- **Color VALUES are transcribed verbatim** from the two authoritative existing files (they already agree): `shroomkit/Sources/ShroomKit/Theme/Palette.swift` (Swift names + hex) and `shroomgames-site/styles/tokens/colors.css` (CSS names + hex). No value changes.
- **CSS theming mechanism:** `[data-theme="forest"]` (also `:root`) and `[data-theme="twilight"]` selector blocks — NOT `prefers-color-scheme` (matches the site's `theme-toggle.js`).
- **CSS variable names match the site's existing `--shroom-*` scheme** (see the name-map table in Task 1). Web-only chrome colors (`--shroom-frame`, `--shroom-island`, `--home-bar`) emit to CSS only, never Swift.
- **Rationalized scales (define + emit, do NOT adopt in app views this phase):**
  - Radii: `sm 10, md 12, lg 14, xl 16, 2xl 18, pill 22`
  - Spacing: `2xs 4, xs 8, sm 12, md 16, lg 24, xl 32`
  - Type primitives: design `rounded`/`mono`; weight `regular 400, medium 500, semibold 600, bold 700`; tracking `normal 0, eyebrow 1.3, wide 2`
- **Generator is a deliberate step** — `npm run build:tokens`, NOT wired into `swift build` (keep SwiftPM Node-free). Generated files carry a `// Generated by Style Dictionary — do not edit.` header and are committed alongside token changes.
- **Generated Swift radii/spacing are `CGFloat`.**

- [ ] **Step 4: Write the Style Dictionary build with the CSS format**

Create `shroomkit/tokens/build.mjs`. Custom CSS format emits `:root, [data-theme="forest"] { … }` and `[data-theme="twilight"] { … }` using each token's `$extensions.shroom.css` name; radii/space/font fall back to a derived `--<group>-<leaf>` name. Skips `swiftOnly` tokens.

```js
import StyleDictionary from 'style-dictionary';

const GEN_HEADER = 'Generated by Style Dictionary — do not edit.';

// CSS var name for a token: explicit override, else --group-leaf (kebab).
function cssVar(token) {
  const override = token.$extensions?.shroom?.css;
  if (override) return override;
  return '--' + token.path.join('-').toLowerCase();
}
function isSwiftOnly(t) { return t.$extensions?.shroom?.swiftOnly === true; }
function isCssOnly(t)   { return t.$extensions?.shroom?.cssOnly === true; }

function dimPx(token) {
  // dimension values are unitless numbers-as-strings → append px for CSS
  const v = String(token.$value ?? token.value);
  return /^[0-9.]+$/.test(v) ? `${v}px` : v;
}

StyleDictionary.registerFormat({
  name: 'shroom/css',
  format: ({ dictionary }) => {
    const all = dictionary.allTokens.filter((t) => !isSwiftOnly(t));
    const isColor = (t) => t.$type === 'color';
    const themeBlock = (theme) => all
      .filter((t) => isColor(t) && t.path[0] === 'color' && t.path[1] === theme)
      .map((t) => `  ${cssVar(t)}: ${t.$value};`).join('\n');
    const webBlock = all
      .filter((t) => isColor(t) && t.path[1] === 'web')
      .map((t) => `  ${cssVar(t)}: ${t.$value};`).join('\n');
    const scaleBlock = all
      .filter((t) => t.$type === 'dimension' || t.$type === 'fontWeight' || t.$type === 'fontFamily')
      .map((t) => {
        const val = t.$type === 'dimension' ? dimPx(t) : String(t.$value);
        return `  ${cssVar(t)}: ${val};`;
      }).join('\n');
    return [
      `/* ${GEN_HEADER} */`,
      `:root, [data-theme="forest"] {`,
      themeBlock('forest'),
      webBlock,
      scaleBlock,
      `}`,
      ``,
      `[data-theme="twilight"] {`,
      themeBlock('twilight'),
      `}`,
      ``,
    ].join('\n');
  },
});

const sd = new StyleDictionary({
  source: ['tokens/tokens.json'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'tokens/build/',
      files: [{ destination: 'tokens.css', format: 'shroom/css' }],
      options: { outputReferences: false },
    },
  },
});

await sd.buildAllPlatforms();
```

- [ ] **Step 4: Add Swift formats + platform to build.mjs**

Append to `shroomkit/tokens/build.mjs` (before `new StyleDictionary(...)`), two formats — one regenerates `Palette.swift`, one emits the scales — then add a `swift` platform. Swift hex literal from `#RRGGBB`:

```js
function swiftHex(token) {
  // resolved color value "#RRGGBB" → 0xRRGGBB
  return '0x' + String(token.$value).replace('#', '').toUpperCase();
}

// Swift-legal leaf names (no leading digit).
const SWIFT_SCALE_NAME = { '2xs': 'xxs', '2xl': 'xxl' };
function swiftLeaf(name) { return SWIFT_SCALE_NAME[name] ?? name; }

const PALETTE_ORDER = [
  'appBg','boardBg','text','sub','pill','accent','accentText',
  'tileCovered','tileCoveredHi','tileCoveredEdge','tileRevealed','tileRevealedEdge',
  'mushroomCap','mushroomStem','mushroomSpot','explodeBg',
  'markerPost','markerSign','markerInk','emptyMark','tierBorder','tierBg','tierSelBg',
];

StyleDictionary.registerFormat({
  name: 'shroom/palette-swift',
  format: ({ dictionary }) => {
    const colorFor = (theme, name) =>
      dictionary.allTokens.find((t) => t.path[0] === 'color' && t.path[1] === theme && t.path[2] === name);
    const themeStatic = (theme) => {
      const lines = PALETTE_ORDER.map((n) => `        ${n}: Color(hex: ${swiftHex(colorFor(theme, n))})`);
      const nums = ['.clear'];
      for (let i = 1; i <= 8; i++) {
        const t = dictionary.allTokens.find((x) => x.path[1] === theme && x.path[2] === 'numberColors' && x.path[3] === String(i));
        nums.push(`Color(hex: ${swiftHex(t)})`);
      }
      lines.push('        numberColors: [\n            ' + nums.join(',\n            ') + '\n        ]');
      return `    public static let ${theme} = Palette(\n${lines.join(',\n')}\n    )`;
    };
    return [
      `// ${GEN_HEADER}`,
      `import SwiftUI`,
      ``,
      `public struct Palette: Sendable {`,
      PALETTE_ORDER.map((n) => `    public let ${n}: Color`).join('\n'),
      `    public let numberColors: [Color]`,
      ``,
      `    public init(`,
      [...PALETTE_ORDER.map((n) => `        ${n}: Color`), `        numberColors: [Color]`].join(',\n'),
      `    ) {`,
      [...PALETTE_ORDER.map((n) => `        self.${n} = ${n}`), `        self.numberColors = numberColors`].join('\n'),
      `    }`,
      `}`,
      ``,
      `extension Palette {`,
      themeStatic('forest'),
      ``,
      themeStatic('twilight'),
      ``,
      `    public static func palette(for appearance: Appearance) -> Palette {`,
      `        switch appearance {`,
      `        case .forest:   return .forest`,
      `        case .twilight: return .twilight`,
      `        }`,
      `    }`,
      ``,
      `    public static func palette(for scheme: ColorScheme) -> Palette {`,
      `        scheme == .dark ? .twilight : .forest`,
      `    }`,
      ``,
      `    /// Semantic alias: over-fill / warning tone, shared with the mushroom cap.`,
      `    public var warn: Color { mushroomCap }`,
      `}`,
      ``,
    ].join('\n');
  },
});

StyleDictionary.registerFormat({
  name: 'shroom/scales-swift',
  format: ({ dictionary }) => {
    const dims = (group) => dictionary.allTokens
      .filter((t) => t.path[0] === group && t.$type === 'dimension')
      .map((t) => `    public static let ${swiftLeaf(t.path[1])}: CGFloat = ${t.$value}`).join('\n');
    const weights = dictionary.allTokens
      .filter((t) => t.path[0] === 'font' && t.path[1] === 'weight')
      .map((t) => `    public static let ${t.path[2]}: Int = ${t.$value}`).join('\n');
    const tracking = dictionary.allTokens
      .filter((t) => t.path[0] === 'font' && t.path[1] === 'tracking')
      .map((t) => `    public static let ${t.path[2]}: CGFloat = ${t.$value}`).join('\n');
    return [
      `// ${GEN_HEADER}`,
      `import CoreGraphics`,
      ``,
      `public enum Radius {`, dims('radius'), `}`,
      ``,
      `public enum Space {`, dims('space'), `}`,
      ``,
      `public enum FontWeightToken {`, weights, `}`,
      ``,
      `public enum FontTracking {`, tracking, `}`,
      ``,
    ].join('\n');
  },
});
```

## Notes for the implementer

- **Style Dictionary v4 API:** custom formats receive `{ dictionary }` with `dictionary.allTokens` (flattened, with `.path` arrays and resolved `$value`). If the installed v4 minor differs, the format-function shape is stable; `transformGroup: 'css'` and the `name/camel` transform are built-ins. Verify with the Step 5 greps — they catch any API drift.
- **Why colors are canonical-as-Swift-names:** the `Palette` API is the established vocabulary and is frozen, so the token leaf name = Swift name needs no override; only the CSS name (the site's `--shroom-*`) is stored per token. This keeps the mapping in one place.
- **Adoption is out of scope:** no rootline/shroomsweeper view is edited to use `Radius`/`Space`/type tokens in this phase — that's Phase 2. This plan only makes them exist and proves the pipeline.
- **Regeneration discipline:** never hand-edit `Palette.swift`, `Tokens.generated.swift`, or `generated.css`. Change `tokens.json` (or the formats) and re-run `npm run build:tokens`.
